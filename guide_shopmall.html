주문/주문서 설정
구매 제한 · 예약 주문 · 간단 회원가입
▼
[관리자] 쇼핑몰 설정 > 주문 설정 > 주문 정책 설정 > 주문 시 설정
1구매 제한
  • 회원만 구매 가능 선택 시 구매 버튼이 회원에게만 노출
  • 비회원에게도 구매 버튼 보이기 별도 설정 가능
  • 14세 미만 구매 차단 선택 시 아이핀 인증 팝업 노출 → 인증 후 구매 가능
2예약 주문 기능
  • 예약 주문 받으려면 상품의 품절 기능 사용 안 함 + 재고관리 기능으로 재고 수량 기재 필요
  • 사용함 선택 시 옵션 선택 시 예약 주문 표시되며, 구매하기 버튼이 예약 주문 버튼으로 변경
3주문서 페이지 간단 회원 가입
  • 비회원이 주문서 작성 화면에서 입력한 정보로 회원 가입 가능
  • 아이디/비밀번호만으로 가입 가능
⚠️
간단 회원 가입 사용 시 회원 가입 인증, 14세 미만 가입 제한, 19세 미만 제한, 성별 가입 제한 등 회원가입에 설정된 기능이 적용되지 않음.

가입 인증 · 연령 제한 · 성인 인증 · 재가입 제한
▼
[관리자] 쇼핑몰 설정 > 고객 설정 > 회원정책 설정 > 회원 관련 설정
1회원가입 항목 표시 설정
  • 기본항목 / 상세항목 으로 구분하여 설정 가능
2연령 제한 설정
설정요구사항
14세 미만 가입 제한본인인증 수단 적용 필요. 14세 미만 고객은 법정 대리인 동의서 확인 후 회원 인증 가능
19세 미만 가입 제한본인인증 수단 적용 + 쇼핑몰 환경 설정에서 인트로 설정 필요
3성인인증 사용 시 19금 이미지 노출
  • 성인 인증 안 한 고객에게 상품 이미지 대신 19금 이미지 노출 가능
  • 상품 분류 관리 메뉴에서도 성인인증 사용함 설정 필요
  • 기본 제공 19금 이미지는 FTP 통해 변경 가능
4회원 재가입 제한
  • 회원 탈퇴/삭제 후 일정 기간 이후 재가입 가능하도록 설정
  • 본인 인증 수단 설정 필요
⚖️
재가입 제한 적용 시 개인정보 처리 방침 / 쇼핑몰 이용약관 / 운영정책 개정이 필요할 수 있음.

적립금 설정
지급 시점 · 사용 제한 · 결제수단별 예외
▼
[관리자] 쇼핑몰 설정 > 고객 설정 > 회원 정책 설정 > 적립금 설정
1기본 설정
  • 지급 시점: 배송완료 후 또는 구매확정 후 어느 시점 이후 적용 설정 가능
  • 설정 변경 이후 주문건에만 적용
⚠️
적립금 지급 기간을 너무 짧게 설정하면 → 고객이 적립금으로 다른 상품 먼저 구매 후 원래 주문 취소하는 악용 사례 발생 가능. 유의 필요.
2지급 설정
  • 상품 구매금액 기준 설정 (항목별 계산식 다름, 툴팁 계산식 참고)
  • 적립금으로 구매 시 처리 방식: 그대로 적립 / 적립 안함 / 차등 지급 / 실 결제금액 기준 적립
  • 회원 가입 시 / 이메일·SMS 수신 동의 시 적립금 지급 여부 설정 가능
3사용/제한 설정
  • 적립금 사용 가능 최소 상품 구매액 / 최소 누적 금액
  • 1회 사용 적립금 한도 설정
  • 적립금 지급 제외 회원등급 / 결제수단 설정
  • 결제수단별 적립금 사용 예외 설정
  • 지정된 상품 또는 분류 포함 상품 예외 설정

1기본 vs 상세 비교
구분특징
기본 항목 표시회원가입항목 / 회원정보 수정항목 2가지 탭으로 구분 설정
상세 항목 표시탭 구분 없이 한 페이지에 모든 항목 표시. 생년월일·성별·별명·결혼기념일·환불계좌정보·추천인 아이디 등 추가정보 항목 설정 가능
🚫
기본 항목 표시 사용 시 사용 불가 기능
• 회원 가입 인증
• 14세/19세 미만 가입 제한
• 성별 가입 제한
• 회원 가입 입력 정보 확인
• 본인 인증 서비스 설정
• 비밀번호 확인 시 질문/답변 기능

▼

1지원 매체
  • 네이버, 카카오, 구글, 페이스북, 라인, 애플, 야후재팬
  • 매체별 Client(App) ID 발급 방법은 가이드 참고 필요
⚠️
주요 유의사항
• 설정한 정보는 변경이 어려워 신중히 입력 필요
• 매체와 설정에 따라 생년월일·본인 인증 정보 미수집 가능 → 성인 인증 필요한 쇼핑몰 사용 불가
• SNS 계정으로 가입 후 탈퇴 시 동일 SNS 계정으로 재가입 불가
• Client(App) ID 변경 시 → 기존 회원/주문 정보 미연동, 새로운 고객으로 가입됨
• 연동 후 로그인 버튼 표시는 디자인 수정 필요

주문 관련
주문서 노출 · 할인 표시 · 취소/반품 처리
▼
주문서 작성 시 주문자 정보 입력칸이 노출되지 않아요
[관리자] 쇼핑몰 설정 > 주문 설정 > 주문 정책 설정 > 주문 시 설정에서 주문서 입력 정보 구성을 주문/배송 정보 개별 입력으로 변경. 배송정보만 입력으로 설정되어 있으면 주문자 정보가 노출되지 않음.
장바구니와 주문서에 각종 할인 금액이 노출되지 않아요
상품 정보 표시 설정 + 할인판매가 표시기준 확인 필요. 상품 관련 설정에서 상품의 할인가 + 회원등급별 할인가 표시 선택 시 각 할인 혜택을 상세 표시 가능.
고객이 반품/교환 시 배송비 결제할 수 있도록 하고 싶어요
주문 후 설정의 구매자 부담 배송비 항목에서 교환/반품 배송비 설정. 0원으로 설정 시 무료 처리되니 주의.
주문 취소되면 재고수량 복구가 가능한가요?
주문 후 설정의 입금/환불/반품 처리 설정에서 취소·교환·반품·환불 처리 시 자동 수량 복구 사용함으로 설정.
구매자 교환/반품 신청 시 택배사에서 반품상품을 자동수거할 수 있나요?
택배사 자동 수거 연동은 택배사 계약 + 자동 수거 서비스 신청이 필요. 어드민에서는 구매자 취소/교환/반품 신청 사용 설정 후, 택배사 측 자동 수거 연동 설정과 함께 운영해야 함.

상품 진열/표시 관련
진열 안 됨 · 회원만 가격 · 할인가 표시 · 순서
▼
쇼핑몰에 상품이 진열되지 않아요
체크 포인트:
• 상품 상태 진열함 / 판매함 여부
• 분류 등록 여부
• 품절 또는 진열 기간 설정 여부
• 소비자가 0원 → 상품 관련 설정의 0원 상품 진열안함인지
• 노출 기간 내인지
회원에게만 상품 가격을 표시하고 구매할 수 있게 하고 싶어요
상품 관련 설정에서 회원/비회원 가격표시를 회원만 표시함으로 설정 + 상품 정보 표시 설정에서 판매가 회원만 노출 + 비회원 표시문구 설정. 구매 자체를 회원만 가능하게 하려면 주문 시 설정에서 회원만 구매 가능으로 별도 설정.
상품 할인 혜택 적용 시 상품에 할인가를 표시하려면 어떻게 하나요?
상품 관련 설정의 할인판매가 표시기준에서 상품의 할인가 + 회원등급별 할인가 표시 선택. 그러면 각 할인 혜택과 회원등급별 할인 혜택이 상세 표시됨.
할인판매가와 판매가를 동시에 표시할 경우 판매가에 취소선 적용하고 싶어요
상품 정보 표시 설정의 추가설정에서 소비자가/판매가 취소선 표시 설정. 상품 정보 일괄 변경에서 소비자가 취소선 일괄 설정도 가능.
쇼핑몰 관리자에서 진열 순서를 설정했는데 쇼핑몰에서는 설정한 순서로 보이지 않아요
분류의 상품진열 방식이 자동정렬만 선택되어 있으면 사용자 지정 순서가 반영되지 않음. 사용자지정 또는 자동정렬+사용자지정으로 변경 필요.

회원/등급 관련
탈퇴 재가입 · 14세 가입 · 등급 자동 변경
▼
탈퇴한 아이디로 재가입은 안 되나요?
회원 관련 설정의 회원 재가입 제한에서 일정 기간 이후 재가입 가능하도록 설정. 본인 인증 수단 설정이 필요하며 이용 약관/정책 개정도 필요할 수 있음.
만 14세 미만 고객도 쇼핑몰에 회원 가입할 수 있나요?
가능. 단 본인인증 수단이 적용되어야 하며, 인증 후 이용 선택 시 14세 미만 고객은 법정 대리인 동의서 확인 후 회원 인증 가능.
고객 구매에 따라 회원등급을 자동으로 변경하고 싶어요
회원 등급 관리에서 회원등급 자동 변경 설정을 통해 일정 기간 구매 이력에 따라 등급 자동 변경. 등급 기준·변경 기준 설정 + 회원등급 목록 우선 순위 입력 필요.
회원 가입할 때 휴대폰 본인인증을 했는데 또 휴대폰 번호를 인증하라고 떠요
본인인증 절차와 주문서 입력 시 인증이 별도일 수 있음. 주문서 입력 항목 설정에서 휴대전화 항목 필수/선택 설정 확인 + 결제수단(에스크로 등) 별도 인증 요구 여부도 점검.
회원가입 시 고객의 주소, 생일 등 추가 정보를 받을 수 있나요?
회원 가입 항목 설정을 상세 항목 표시로 변경. 생년월일, 성별, 별명, 결혼기념일, 환불계좌정보, 추천인 아이디 등 추가정보 항목 사용 가능.

적립금 설정의 사용/제한 설정에서 지정된 상품 또는 분류 포함 상품 예외 설정 가능.

사용 가능 최소 상품 구매액 / 최소 누적 금액, 1회 사용 적립금 한도, 결제수단별 사용 예외 등 다양한 사용 제한 설정 가능.
미가용 적립금이 무엇이며, 어떻게 확인하나요?
지급 시점이 도래하지 않아 사용할 수 없는 적립금. [관리자] 고객 > 회원 혜택 관리에서 가용/미가용 적립금 구분하여 확인 가능. 회원별 상세 내용에서도 미가용 내역 확인 가능.

SNS 로그인 연동 기능으로 가입한 회원은 탈퇴 후 재가입 할 수 없나요?
SNS 로그인 연동 정책상 SNS 계정으로 가입했다가 탈퇴하면 동일한 SNS 계정으로 재가입 불가. 일반 회원으로의 재가입은 회원 재가입 제한 설정에 따름.
사용중인 SNS 로그인 수단의 Client ID값을 변경하거나 사용안함으로 변경하고 싶어요
Client(App) ID 변경 시 → 기존 회원 정보, 주문 정보 등과 연동되지 않아 새로운 고객으로 가입됨. 변경/사용안함 처리 전 영향 범위 충분히 검토 필요.

SMS/메시지 관련
발송 · 미수신 · 발신번호 · 자동 발송 · 변수
▼
SMS는 어떻게 이용하나요?
발신번호 등록 + 충전 후 메시지 사용 설정에서 SMS 사용함으로 설정. 자동 알림 메시지 관리에서 상황별 메시지 설정.
고객에게 SMS 발송했는데 고객은 수신하지 못했어요
체크 포인트:
• 고객의 SMS 수신 거부 여부
• SMS 사용 설정에서 수신 거부 회원 발송 여부 설정
• 광고성 정보 발송 시 무료 수신 거부 전화번호 설정
• 90byte 초과 메시지 처리 설정
SMS 발신번호 등록 어떻게 하나요?
통신사 정책에 따라 발신번호 사전 등록 의무화되어 있음. 메시지 사용 설정의 SMS 탭에서 발신번호 등록 절차 진행 (소유 인증 필요).
자동 SMS가 발송되지 않아요
체크 포인트:
• SMS 잔여 충전금액
• 메시지 사용 설정의 사용함 여부
• 자동 알림 메시지 관리의 수신 대상 체크
• 알림톡 사용 시 반려 템플릿 존재 여부 (반려 템플릿 있으면 발송 실패)
쿠폰 만료 예정 안내 알림 메시지 보내고 싶어요
자동 알림 메시지 관리에서 쿠폰 만료 예정 안내 메시지 활성화 + 수신 대상 체크. 카카오 알림톡으로 발송 가능 여부도 확인.
SMS 또는 카카오알림톡 발송시 사용가능한 변수는 무엇인가요?
자동 알림 메시지 관리에서 사용 가능 변수 보기 클릭. 단, SMS 본문에 이모티콘 사용 불가이며 상품명·쿠폰이름 등에 이모티콘 포함 시 체크 필요.

혜택/결제 관련
사은품 미지급 · SNS 리워드 · PG 에스크로
▼
사은품 증정혜택 진행중인데 사은품 지급이 안되었어요
체크 포인트:
• 혜택 환경 설정의 사은품 기능 사용함 여부
• 지급 형태 (자동지급형은 품절 시 미지급)
• 사은품 제공 계산 범위/방식 일치 여부
• 구매 가격 범위 충족 여부
• 첫구매 한정 시 회원 여부
SNS 로그인을 통해 가입한 고객도 리워드 혜택을 받을 수 있나요?
SNS 로그인은 매체와 설정에 따라 본인 인증 정보 미수집될 수 있음. 본인인증 기반의 리워드(추천인 적립금 등)는 일부 SNS 회원에게 제한될 수 있어 사전 확인 필요.
무통장 계좌 등록 시 보안 인증 오류 알림창이 떠요
대표 휴대폰/대표 이메일 인증 정보가 정확한지 확인. [관리자] 쇼핑몰 설정 > 기본 설정 > 내 쇼핑몰 정보에서 대표 인증 정보 변경 후 재시도.
PG 에스크로는 쇼핑몰에 어떻게 적용하나요?
결제 방식 설정의 매매보호 서비스에서 PG 에스크로 사용함 설정. 결제사에서 신청 후 계약 완료 시 자동 사용안함으로 설정될 수 있어, 적용 후 사용 여부 재확인 필요. 한국정보통신은 휴대전화 필수 항목 설정도 함께 필요.

배송 관련
배송비 미부과 · 지역별 · 고객직접선택 · 일괄 등록
▼
배송비를 설정했으나 배송비가 부과되지 않아요
체크 포인트:
• 무료배송 우선 설정으로 인한 면제 여부
• 개별 배송비/공급사 배송비 우선 적용 여부
• 배송비 할인 혜택 진행 여부
• 결제 시점 할인으로 인한 배송비 0원 처리 여부
지역별 배송비 설정은 어떻게 하나요?
배송비 설정에서 간편설정(제주·도서산간 일괄 입력) 또는 우편번호 설정(지역별 상세 등록) 선택. 실제 주소와 동일한 지역명 입력 필수.
배송방법을 고객이 직접 선택하는 방법은 어떻게 되나요?
배송비 설정의 배송방법을 고객 직접 선택으로 설정. 배송업체 관리에서 등록된 업체들이 주문서에 표시됨.
지역별 배송비를 일괄 등록할 수 있나요?
지역별 배송비 설정에서 엑셀 양식 다운로드 → 작성 → 업로드로 일괄 등록 가능. 파일은 xlsx/xls 권장. 실패 항목이 1개라도 있으면 업로드되지 않음에 유의.

운영자/멀티쇼핑몰 관련
부운영자 권한 · 로그 확인 · 멀티몰 관리
▼
부운영자가 회원정보 조회 시 검색조건을 입력하라고 떠요
부운영자에 회원 정보 검색 권한 제한이 적용된 상태. 이름·아이디 정확히 일치해야 검색 가능. 운영자 계정 관리에서 권한 설정 변경 가능.
상품 수정이력이나 쇼핑몰 관리자 로그인 기록 확인할 수 있나요?
[관리자] 쇼핑몰 설정 > 운영자 설정 > 운영자 관리 > 업무 처리 관리에서 운영자/부운영자/공급사 업무 처리 내역 확인. 로그인 + 고객 정보, 상품, 주문 관련 내역 확인 가능. 기본 로그 보관 2년, 권한 부여/변경/말소는 5년.
멀티쇼핑몰 관리는 따로 어떻게 하나요?
[관리자] 쇼핑몰 설정 > 채널 설정 > 카페24 채널 > 멀티쇼핑몰에서 추가/설정. 한 번 가입으로 최대 15개 쇼핑몰 무료 운영 가능. 단, 기본 쇼핑몰 언어/결제화폐 변경 불가, 주문 발생 후 결제화폐 수정 불가 등 제약사항 다수 있음.
