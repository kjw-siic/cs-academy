📌

2적용 범위 (해외몰)
  • 기본/공급사/개별 배송비, 해외 배송 보험료, 해외 배송 부가 금액, 지역별 배송비 등 무료 할인 가능
3혜택 제공 금액 기준 설정
  • 사용함 설정 시: 총 주문 금액(할인 적용 전 상품 구매 금액 기준) 기준으로 적용
⚠️
혜택 제공 금액 기준이 "사용 안함"인 경우 → 주문 금액과 관계없이 배송비가 무조건 할인 처리됨.
동일 조건의 다른 혜택이 진행 중이면 가장 먼저 등록된 혜택이 적용됨.

사은품 증정
상품 구매 시 사은품 지급 · 첫구매 한정
▼
1주요 설정 항목
  • 기간 설정: 증정품 제공 기간
  • 사용 범위: PC / 모바일 / 앱
  • 참여 대상: 회원/비회원, 회원 선택 시 등급별 적용
  • 상품 범위: 적용 대상 상품·분류 지정 또는 특정 상품 제외
2첫 구매 한정 설정
  • 처음 구매할 때만 제공 (주문 결제 취소 여부와 무관)
  • 회원에게만 제공 — 참여 대상을 "회원+비회원"으로 설정해도 비회원에게는 적용 안 됨
3구매 가격 범위
  • 설정한 금액 범위 내에서만 사은품 지급
  • 계산 방식은 [쇼핑몰 설정] 프로모션 설정 > 혜택 환경 설정의 "사은품 제공 계산 범위 설정"에 따라 다름
📌
사전 설정 필수: [쇼핑몰 설정] 프로모션 설정 > 고객혜택 설정에서 사은품 기능 사용 여부 사용함 설정 + 사은품 선택 단계 항목에서 선택 방법 설정 필요.
🎉
1+N 이벤트
1개 구매 시 N개 추가 증정
▼
1주요 설정 항목
  • 기간/참여 대상/상품 범위 설정 (사은품 증정과 유사)
  • 상품 선택: 세트 상품·추가 구성 상품·관련 상품 제외, 기본 상품만 설정 가능
💡
1+N 이벤트 상품은 장바구니에서 수량 변경 불가.
2유의사항
  • 할인 적용 상품과 중복 설정 가능
  • 구매주문단위·최소/최대 주문수량 설정이 있으면 1+N 이벤트 설정이 우선 적용됨
  • 옵션별 추가 금액이 있는 상품은 증정 상품으로 추가 불가
  • 상품 추가 후 옵션별 추가 금액 수정 시 주문 시 0원 처리되므로 유의
  • 상품 연동형 옵션 등록 상품 추가 시 1+N 이벤트 설정 적용되지 않음
🚫
사은품 또는 1+N 이벤트로 등록된 상품은 네이버페이 버튼 노출되지 않음. 사은품은 쇼핑몰 주문서 페이지 주문 완료 시 선택하는 구조라 네이버페이 적용 불가.

1주요 버튼 기능
버튼기능
발급쿠폰 발급하기 화면 → 회원/조건 선택해 쿠폰 발급
조회쿠폰 발급 내역 관리 → 발급/사용 일자, 주문번호, 사용 여부 확인
설정 복사발급된 쿠폰과 동일 설정으로 새 쿠폰 생성
경로 복사쿠폰 다운로드 URL 복사 (고객 다운로드 쿠폰만 표시)
일괄 관리쿠폰 선택 후 일괄 발급 또는 회수
2삭제 vs 완전 삭제
삭제 버튼
  • 쿠폰이 삭제되어도 이미 발급된 쿠폰은 회수되지 않음
  • 발급받은 고객은 계속 사용 가능
완전 삭제 버튼
  • 이미 발급된 쿠폰도 회수됨
  • 처리 시 주의 필요
  • 쿠폰 목록에 표시되지 않으며, 검색 조건의 삭제 여부 선택 시 확인 가능
⚖️
법적 유의사항 — 쿠폰 임의 삭제 금지
• 이미 발급된 쿠폰은 회원의 자산으로 법적 보호 대상
• 약관에 회수 조항이 없으면 사전 고지 필수
• 임의 삭제 시 전자금융거래법, 표시 광고 공정화법, 전자상거래법 저촉
• 상품권성 쿠폰: 유효기간 경과 후에도 5년 이내 90% 환불 필요
• 소셜커머스 발급 쿠폰: 유효기간 경과 후 구입가 70% 환불 필요

[관리자] 프로모션 > 할인코드
1할인코드 등록 절차
할인코드 등록 → 기본정보 필수항목 기재 → 사용기간/적용 범위 선택 → 제한 정보 설정 → 저장
2제한 정보 설정 항목
제한 항목설정 시 동작
사용 가능 최소 주문 금액제한함 선택 시 최소 주문 금액 설정 가능
최대 사용 가능 횟수제한함 선택 시 할인코드 사용 총 횟수 설정 가능
사용 가능 대상회원만 사용하도록 설정 가능
동일인 사용 가능 횟수제한함 선택 시 회원당 사용 횟수 설정 가능 (비회원 미적용)
📌
• 입력 코드는 1~35자리 영문/숫자로만 등록 가능
• A·B 상품에 할인코드 적용 시, 고객은 A·B 상품에 각각 적용하여 할인 받을 수 있음 — 비율 설정 시 유의
• 진행 전 코드는 모든 정보 수정 가능, 진행중/종료 코드는 일부만 수정 가능
3할인코드 조회
  • 기간·할인코드 이름·입력코드로 검색
  • 사용 기간 시작 전: 잔여 횟수/총 횟수 → "진행 전" 표시
  • 사용 기간 시작 후: 잔여/총 횟수 표시
  • 엑셀 다운으로 사용 내역 다운로드, 복사로 동일 설정 코드 생성, 삭제 가능

1회원 정보 수정 이벤트
  • 회원 정보를 최신으로 업데이트하도록 유도하는 이벤트 (SMS·이메일 수신 동의 유도 가능)
  • 이벤트 기간 중 회원 로그인 시 이벤트 진행 알림 팝업 노출
  • 기간 내 정보 수정한 회원에게 혜택 지급
2비밀번호 변경 이벤트
  • 회원 개인정보 보호 · 도용 피해 예방 목적
  • 로그인 시 최근 비밀번호 변경일이 설정 기간을 지났다면 비밀번호 변경 화면으로 자동 연결
  • 변경한 회원에게 자동 혜택 지급
3평생회원 전환 이벤트
구분특징
평생회원탈퇴 시까지 휴면 처리되지 않음 (휴면 기능 사용 중이라도 미전환)
일반회원마지막 로그인 1년 경과 시 휴면 회원으로 자동 전환
  • 이벤트 기간 내 평생회원 가입한 신규/기존 회원에게 쿠폰 혜택 지급 가능

리워드 프로그램 (추천인)
추천인/피추천인 적립금 · 악용 방지
▼
[쇼핑몰 설정] 프로모션 설정 > 리워드 프로그램 설정
1용어 정리
구분설명
추천인기존 가입자로서 쇼핑몰 가입·구매를 홍보해 회원 유치에 도움을 주는 회원
피추천인추천인의 추천을 받아 신규로 회원 가입·구매를 하는 회원
2설정 사전 작업
  • [쇼핑몰 설정] 고객 설정 > 회원 가입 항목 설정에서 추천인 아이디 항목 사용 설정
  • [쇼핑몰 설정] 프로모션 설정 > 리워드 프로그램 설정에서 추천인 적립금 사용설정 사용함
3홍보 URL
  • PC/모바일 마이페이지에 회원 ID 포함 홍보 URL, 주소 복사 버튼 표시 가능
  • URL 형식: http://쇼핑몰도메인/?reco_id=추천인아이디
  • 표시 여부와 관계없이 URL 자체는 사용 가능
4피추천인 수 제한
  • 추천인 수 제한은 추천 등록 수가 아닌 적립금 지급 혜택을 받은 횟수 기준
  • 피추천인이 탈퇴해도 추천 가능 명수에서 제외되지 않음

할인 혜택 관련
기간/재구매/대량/회원등급/배송비 할인
▼
기간 할인 혜택은 어떻게 등록하나요?
[관리자] 프로모션 > 고객 혜택 관리 > 혜택 등록에서 할인 → 기간 할인 선택. 기간/사용 범위(PC·모바일·앱)/참여 대상(회원·비회원, 회원 시 등급별)을 설정.
재구매 혹은 대량구매 회원에게 할인 혜택을 주고 싶어요
혜택 등록에서 재구매 할인(동일 상품 N회 이상 구매) 또는 대량 구매 할인(동일 상품 N개 이상 구매) 선택. 재구매 할인은 회원에게만 설정 가능. 상품 범위와 구매 횟수/수량을 조건으로 설정.
회원 등급별 할인 혜택을 제공할 수 있나요?
대부분의 할인 혜택(기간/대량구매/배송비/사은품 등)에서 참여 대상을 회원으로 선택 시 등급별 적용 가능. 등급별로 다른 할인율 적용하려면 등급 수만큼 별도 혜택 등록 필요.
배송비 무료 이벤트를 진행하려면 어떻게 해야 하나요?
혜택 등록 → 할인 → 배송비 할인 선택. 기본/공급사/개별 배송비 무료 처리 가능, 지역별 배송비 포함 여부 설정 가능. 해외배송·네이버페이·마켓 주문에는 적용되지 않음.

증정 혜택 관련
사은품 미지급 · 1+1 이벤트 설정
▼
사은품 증정 혜택 진행 중인데 사은품 지급이 안 되었다고 해요
체크 포인트:
• [쇼핑몰 설정] 프로모션 설정 > 고객혜택 설정에서 사은품 기능 사용함 설정 여부
• 사은품 재고 품절 여부 (자동지급형은 품절 시 미지급)
• 구매 가격 범위 충족 여부
• 첫구매 한정 설정 시 회원 여부 (비회원에는 미적용)
• 혜택 환경 설정의 사은품 제공 계산 범위/방식 일치 여부
1+1 이벤트 및 사은품 증정 설정은 어떻게 하나요?
혜택 등록에서 증정 → 사은품 증정 또는 1+N 이벤트 선택. 1+N 이벤트는 기본 상품만 추가 가능 (세트·추가 구성·관련 상품 제외), 옵션별 추가 금액 있는 상품 불가. 두 혜택 모두 네이버페이 버튼이 노출되지 않음에 유의.

쿠폰 관련
회원가입/생일/다운로드 쿠폰 · 삭제 회수
▼
회원가입 쿠폰은 어떻게 발행하나요?
[관리자] 프로모션 > 쿠폰 관리에서 쿠폰 생성 후 발급 조건을 회원가입으로 설정. 회원가입과 동시에 자동 발급되도록 구성 가능.
기념일(생일) 쿠폰은 어떻게 발급하나요?
쿠폰 만들기에서 발급 조건을 기념일/생일로 설정. 회원의 생일 정보를 사전 수집해야 정상 발급되며, [쇼핑몰 설정] 회원 가입 항목 설정에서 생년월일 항목 사용 필요.
고객이 할인쿠폰을 직접 다운로드 할 수 있게 설정할 수 있나요?
쿠폰 만들기에서 고객 다운로드 쿠폰으로 설정. 발급된 쿠폰의 경로 복사 버튼으로 다운로드 URL을 받아 쇼핑몰 배너 등에 연결 가능.
이미 발급된 쿠폰/시리얼쿠폰의 적용 대상 상품이나 분류를 변경할 수 있나요?
발행 후 시리얼쿠폰은 쿠폰명, 쿠폰적용 상품 선택, 쿠폰적용 분류 선택만 수정 가능. 일반 쿠폰의 적용 대상 변경도 발급 후에는 제한적이므로 발급 전 신중히 검토 필요.
쿠폰 삭제, 회수, 발급 중단은 어떻게 하나요?
• 삭제: 이미 발급된 쿠폰은 회수되지 않고 고객이 사용 가능
• 완전 삭제: 발급된 쿠폰까지 회수됨 (주의 필요)
• 발급 중단: 일괄 관리 버튼으로 회수 처리 가능
⚖️ 발급된 쿠폰은 회원 자산으로 법적 보호 대상이라 약관에 회수 조항 없으면 사전 고지 필수.

기존 회원들에게 SMS 및 이메일 수신 동의를 받으려면 어떻게 해야 하나요?
회원 정보 수정 이벤트를 활용. 이벤트 기간 중 회원 로그인 시 알림 팝업이 노출되며, 정보 수정한 회원에게 혜택 지급 가능. 수신 동의 항목을 정보 수정 시 함께 받도록 유도.

② [쇼핑몰 설정] 프로모션 설정 > 리워드 프로그램 설정에서 추천인 적립금 사용함
