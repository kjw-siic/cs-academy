기존 유튜브 쇼핑 단독 메뉴가 구글 & 유튜브 통합 메뉴로 개편되었어요. 어드민 경로가 [관리자] 구글 & 유튜브로 변경되었고, Google 판매자 센터 · 유튜브 쇼핑 · Google 애즈 캠페인을 한 곳에서 관리해요.

서비스 개요
🎬
유튜브 쇼핑이란?
영상·라이브 내 상품 소개 및 구매 연결
▼
1핵심 개념
  • 유튜브 영상·라이브 스트리밍 내에서 상품을 소개하고 직접 구매까지 연결되는 기능
  • 라이브 방송 · VOD · Shorts를 활용해 제품 소개 가능
  • 시청자는 콘텐츠를 즐기면서 간편하게 구매 기회를 얻음
2참여 주체별 이점
  • 브랜드/머천트: 채널을 통해 상품 노출 및 판매 경로 확대
  • 크리에이터: 협업 브랜드 제품 태그·제휴 상품 소개로 수익 창출
  • 소비자: 영상 → 상품 상세 → 구매까지 원활히 연결
⭐
카페24 유튜브 쇼핑의 특징
원클릭 연동 · 통합 관리 · 확장 기능
▼
1원클릭 연동 및 간편 설정
  • 카페24 쇼핑몰과 유튜브를 원클릭으로 연동, 별도 개발 없이 시작
  • 기존 쇼핑몰 상품을 자동 동기화해 설정 시간 최소화
2통합 관리 솔루션
  • 카페24 어드민에서 유튜브 쇼핑 주문·배송·CS까지 통합 관리
  • 기존 쇼핑몰 운영 프로세스를 유지하면서 판매 채널만 확장
3카페24 전용 확장 기능
  • 제휴 프로그램: 크리에이터와 제휴하여 상품 노출 범위 확대
  • 체크아웃 프로그램: 유튜브 앱에서 콘텐츠를 보며 바로 구매 연결
시작 · 연동
🚀
구글 & 유튜브는 어디서 시작하나요?
시작 경로 · PG 선수 조건 · 화폐 제한
▼
[관리자] 구글 & 유튜브 > 'Google 판매자 센터 생성하고 시작하기'
1시작 방법
  • [관리자] 구글 & 유튜브 메뉴로 이동 → 'Google 판매자 센터 생성하고 시작하기' 클릭
🚫
선수 조건 (필수)
구글 & 유튜브를 시작하려면 쇼핑몰 PG(결제) 신청이 되어 있어야 해요. PG 신청 전에는 연동을 시작할 수 없어요.
⚠️
쇼핑몰 화폐가 CNY(위안) 또는 PKR(파키스탄 루피)로 설정된 경우 구글 서비스 지원이 되지 않아 연동이 어려워요.
🔗
Google 판매자 계정 연결하기
Google 로그인 · 판매자 센터 생성/연결 · 연동 후 상품 전송
▼
1. Google 로그인→ 2. 판매자 센터 생성/연결 선택→ 3. 필수 약관 동의→ 4. 대시보드 자동 이동
1Google 계정 로그인
  • Google 판매자 계정 생성·연결을 위해 로그인 필요
  • 로그인한 계정은 이후 대시보드의 '연결된 Google 계정'으로 표시돼요
⚠️
Google 계정 연동 시 id@pages.googleplus.com 이메일 형식은 지원하지 않아요. 여러 국가에서 사용되는 화폐인 경우 판매 국가 선택이 필요해요.
2판매자 센터 생성 또는 연결 선택
  • 신규 생성: 로그인한 Google 계정 하위로 새 판매자 센터 계정 생성
  • 기존 연결: 이미 만들어 둔 판매자 센터 계정을 선택해 연결
  • 선택 후 판매자 계정 생성·연결을 위한 필수 약관에 모두 동의 → '다음'
3연동 완료 후 자동으로 일어나는 일
  • 연동이 끝나면 대시보드로 자동 이동, Google 판매자 센터 카드에서 상품 상태 요약 확인 가능
  • 카페24 어드민 상품이 판매자 센터로 자동 업로드·동기화되고, 이후 상품 수정도 실시간 반영
  • 판매자 센터만 연결해 두어도 Google 무료 광고 지면에 상품이 노출돼 자연 유입 증가 효과
⚠️
전체 상품이 판매자 센터로 전송되기까지 일정 시간이 소요될 수 있어요. 연동 직후 "상품이 아직 안 올라가요" 문의는 시간을 두고 상품 피드에서 확인하도록 안내하세요.
💡
자동 동기화가 되더라도 반려된 상품은 직접 사유 확인·수정이 필요해요. → 운영 메뉴 > 상품 피드 카드 참고
📺
유튜브 쇼핑 연결하기
진입 경로 · 채널 선택 · 다른 계정 연결 · YPP · 연동 후 체크
▼
[관리자] 구글 & 유튜브 > 유튜브 쇼핑 > 유튜브 스토어
1진입 경로 (2가지)
  • Google 판매자 센터 계정 생성이 완료된 후에 연결 가능
  • 대시보드 > 유튜브 스토어 서비스 카드의 '시작하기' 클릭
  • 또는 유튜브 쇼핑 > 유튜브 스토어 메뉴에서 시작
2유튜브 채널 선택
  • 로그인한 Google 계정에 존재하는 유튜브 채널을 목록으로 가져옴
  • 연결 가능한 채널 중 1개만 선택 가능
3다른 계정으로 연결하기
  • 채널 일부가 안 보이거나 다른 계정의 채널을 연결할 때 사용
  • '다른 계정으로 연결하기' 클릭 시 유튜브 로그인 팝업 호출
  • 연결 가능한 채널이 있는 유튜브 계정으로 로그인
  • 로그인 시 선택한 채널(브랜드 계정) 또는 계정에 속한 모든 채널이 목록으로 노출
4약관 동의 및 연동 완료
  • 채널 선택 후 모든 약관(필수) 동의 체크 → '동의하고 완료' 클릭
  • 약관 동의 후 유튜브 채널 연동을 시도하며, 이때 채널 자격 검증이 진행돼요
🚫
선택한 채널이 YPP(유튜브 파트너 프로그램)를 만족하는 채널이어야 정상적으로 연동이 완료돼요.
5연동 후 꼭 확인할 것
  • 채널 거주 국가 설정: 유튜브 스튜디오 '설정 > 채널 > 기본정보'에서 거주 국가가 선택되어 있어야 정상 이용 가능
  • 채널이 비공개·삭제되거나 소유자/관리자 권한이 빠지면 유튜브 스토어 이용 불가
  • 인증 토큰이 만료되면 설정 > 확인 필요 탭에 '유튜브 계정 토큰 문제' 알럿이 노출 → '유튜브 재로그인하기'
💡
채널이 노출되지 않는다면, 해당 채널의 소유자 또는 관리자 권한이 있는지 YouTube 스튜디오에서 확인해 주세요.
📋
전체 준비 절차 요약
계정 생성 → 채널 선택 → 결제 → 약관
▼
1. 계정 생성→ 2. 채널 선택→ 3. 결제 설정→ 4. 약관 동의
  • 계정 생성: Google 판매자 계정 생성(기존 회원은 Google 로그인 연동)
  • 채널 선택: 연동할 유튜브 채널 1개 선택 (선택 후 변경 어려움)
  • 결제 설정: 결제 프로필 등록
  • 약관 동의: 특별 약관 동의 후 '시작' → 대시보드 이동
🚫
초기 설정 후 카페24페이먼츠(PG) 계약 완료 + 결제 프로필 정상 상태 유지해야 유튜브 쇼핑 이용 준비가 완료돼요.

유튜브 스토어
채널 연결·상품 공개 일정 관리
▼
[관리자] 구글 & 유튜브 > 유튜브 쇼핑 > 유튜브 스토어
1유튜브 채널 정보
  • 연결한 유튜브 채널 정보 표시, 채널명 클릭 시 해당 채널로 이동
2바로가기 카드
  • 유튜브 쇼핑 성과 확인하기: 유튜브 쇼핑 분석 메뉴로 이동 (기간별/채널별/상품별 성과)
  • 상품 공개일 설정하기: 원하는 시점에 상품 자동 공개 등록·관리
⚠️
채널이 비공개·삭제되었거나 소유자/관리자 권한이 해제되면 유튜브 스토어를 정상 이용할 수 없어요. 구글 & 유튜브 > 설정 > 확인 필요에서 문제를 해결하세요.
🎁
상품 공개 (신상품 공개일 설정)
출시 예정 상품을 원하는 시점에 자동 공개
▼
[관리자] 구글 & 유튜브 > 유튜브 쇼핑 > 유튜브 스토어 > 상품 공개일 설정하기
1상품 공개란?
  • 출시 예정 신상품의 공개일을 설정하는 기능
  • 공개일 설정 상품은 유튜브 콘텐츠(Shorts·Live·VOD)에 미리 태그 가능
2설정 규칙
  • 공개일은 3일 이후 날짜부터 선택 가능, 최대 30일 후까지
  • 시간은 30분 단위로만 설정 가능
  • 승인 상태가 승인 또는 대기인 상품만 설정 가능
  • 최대 100개 상품까지 설정 가능
🚫
공개일 등록 상품은 자동으로 '판매안함'이 되지 않아요. 자사몰에 노출 중이라면 등록 후 '판매안함'·'진열안함' 처리하세요. 공개일시 도래 시 자동으로 '판매함'·'진열함'으로 변경돼요.
⚠️
공개일 등록 후 유튜브 스튜디오로 이동해 콘텐츠에 제품을 태그해야 정상 공개돼요. Shorts·VOD는 공개일 이후 제품이 표시돼요. 공개일 지난 후 12시간이 지나면 공개일 정보는 자동 삭제돼요.

유튜브 쇼핑 분석
매출·유입·전환 성과 · 수집 기준 · 이전 성과 조회
▼
[관리자] 구글 & 유튜브 > 유튜브 쇼핑 > 유튜브 쇼핑 분석
1조회 기간
  • 오늘 / 어제 / 7일 / 1개월 / 3개월 토글 또는 시작일·종료일 직접 선택
  • 선택 기간 직전의 동일 길이 기간이 비교 기간으로 자동 표시
  • 요약 카드의 증감률은 비교 기간 대비 변동 수치
⚠️
유튜브 쇼핑 분석은 2026년 1월 5일 이후 성과부터 제공돼요.
2탭별 분석 (기간 / 상품 / 채널)
탭제공 지표상세보기
기간날짜별 매출액, 구매건수, 유입수, 구매전환율-
상품상품별 판매금액, 판매건수, 판매수량, 상품조회수, 판매전환율상품의 기간별/채널별 상세 성과
채널채널별 매출액, 구매건수, 유입수, 구매전환율채널의 기간별/상품별 상세 성과
  • 수치는 utm_term 파라미터로 수집된 값 기준
  • 각 탭 상단에 요약 카드 + 차트, 우측 상단 '엑셀 다운로드'로 테이블 다운로드
  • 구매분석 차트: 막대(매출액/판매금액) + 라인(구매건수/판매건수), 좌우 2개 Y축으로 매출과 건수 동시 비교
3성과 수집 기준
  • 유튜브 지면에서 카페24 쇼핑몰로 유입된 후 구매가 발생한 주문 기준
  • 주문 URL이 utm_source=youtube 이면서 utm_content가 YT3로 시작하는 경우만 집계
수집 대상
  • 동영상·라이브·Shorts에 태깅된 상품을 클릭해 발생한 주문
  • 유튜브 채널 스토어를 통해 발생한 주문
수집 제외
  • 제휴 프로그램 주문은 합산되지 않음 → 유튜브 제휴 프로그램 메뉴의 '제휴 프로그램 성과'에서 확인
  • UTM 파라미터가 유실·미전달된 주문은 수집되지 않을 수 있음
  • 직접 방문·검색 등 유튜브 외 경로 주문
4이전 성과 확인
  • 상단 '이전 성과 확인하러 가기' 버튼 → 2026년 6월 24일 이전 데이터 별도 페이지 조회
  • 이전 성과 페이지는 기간/채널/상품/콘텐츠 4개 탭 구성
  • 해당 시점의 yts_source 파라미터로 수집된 정보만 표시

3프로그램별 피드
  • 상품은 프로그램마다 승인 상태가 따로 있고, 각 프로그램에서 승인이어야 해당 프로그램에서 사용 가능
  • 연동된 프로그램은 '전체 / 전송 / 제외' 수치 표시, '>' 버튼으로 상세 이동
  • 미연동 프로그램은 '연동하기' 버튼 → 해당 온보딩으로 이동

4상품 피드 상세보기 · 품목별 승인 상태
  • 상세 페이지에서 상품명/상품코드 검색, 기간/상품 상태 필터 사용 가능
  • 체크박스로 선택한 상품을 '전송 포함' / '전송 제외' 일괄 변경
  • 각 상품의 '승인상태' 뱃지를 클릭하면 품목별 승인 상태와 사유 확인
  • 상품은 품목 단위로 Google에 전송·심사되기 때문에, 옵션 상품은 같은 상품이라도 품목마다 승인 상태가 다를 수 있어요
💡
독립선택형 상품의 선택 옵션 품목은 승인 상태가 '대기'로 나올 수 있어요. 이 경우 상품 판매에는 문제가 없어요.

  • 상품 자체에 문제가 없어 보여도 정책 위배 시 반려될 수 있음
  • 반려 사유는 판매자 센터의 해당 상품 상세 페이지에서 확인
  • 상품을 수정하면 판매자 센터에 반영되고 자동으로 재심사 진행
7특정 상품 전송 제외하기
  1. 상품 피드로 이동
  2. 노출하고 싶지 않은 프로그램을 선택해 상세 화면 이동

2결제 프로필 준비
  • 수수료 자동 정산을 위해 Google 결제 프로필 등록 필요
  • American Express · MasterCard · Visa의 해외 또는 국내/외 겸용 신용·체크카드만 가능
  • 국내 전용 카드는 등록 불가
3결제 프로필 등록 절차
  1. '결제 프로필 설정' 단계에서 [결제 프로필 설정하기] 클릭
  2. 새 창으로 열린 Google 판매자 센터에서 앞서 로그인한 Google 계정으로 로그인
  3. 사이트 언어를 '한국어'로 설정 (우측 상단 설정 > 계정 설정 > 시간대 및 언어 > 표시 언어 '한국어(대한민국)')
  4. 세금 정보, 이름 및 주소, 기존 연락처 입력
  5. 카드 세부 정보(카드번호·유효기간·CVC) 입력
  6. 카드 주소가 위 주소와 같으면 동의 체크, 다르면 체크 해제 후 카드 주소 입력
  7. 하단 '계속' 버튼을 눌러야 결제 설정 완료
⚠️
화면에 '월별 정기 결제'라고 표시되지만 실제로 결제되지 않아요. 카드를 등록해도 결제는 발생하지 않으며, 카드 등록 과정에서 카드사 확인 문자가 발송될 수 있어요.
4수수료 설정

  • 카테고리별 수수료: 상품의 표준 카테고리 기준으로 입력, 연동 후 제휴 프로그램 메뉴에서 추가/수정/삭제
  • 기본 수수료: 카테고리별 수수료가 적용되지 않은 상품에 공통 적용

판매자 센터 세팅이 완료되지 않았어요비즈니스 정보·배송 정책 등 연동 중 미완료 항목 존재'판매자 센터 연동 완료하기'로 재시도
사용자 접근 권한이 없어요연결 계정에 판매자 센터 접근 권한 없음, 계정 삭제, 판매자 센터에서 Cafe24 권한 제거판매자 센터에서 사용자 액세스 권한 재설정
판매자 센터에서 계정 문제가 발생했어요판매자 센터 정책 위반 (대표적으로 허위 진술)판매자 센터 가이드 확인 후 직접 해결
연결 계정 토큰에 문제가 발생했어요토큰 만료 또는 인증 끊김'다시 로그인하기'로 Google 재로그인
소유권 확인에 문제가 발생했어요다른 판매자 센터가 쇼핑몰 도메인 소유권을 가져감'소유권 주장하기' 또는 판매자 센터에서 직접 주장
대표 도메인이 변경되었어요쇼핑몰 대표 도메인 변경이 판매자 센터에 미반영'도메인 반영하기'
잘못된 매장 이름이 등록되었어요매장 이름이 도메인 주소로 표시되거나 정책 위반 문구 포함 (Inc./Co. 등 접미사, 홍보성 텍스트, 과도한 대문자·특수문자)쇼핑몰명 수정 후 '비즈니스 정보 수정하기'
⚠️
'소유권 주장하기'를 진행하면 해당 도메인을 쓰고 있던 기존 판매자 센터는 소유권을 잃어요. 고객이 다른 대행사·다른 계정으로 판매자 센터를 운영 중인지 먼저 확인하세요.

5웹사이트 소유권 주의
🚫
유튜브 쇼핑 활성화 시 Google 판매자 센터에 웹사이트 소유권 인증이 자동 완료돼요. 인증된 웹사이트를 수동 변경하면 전송된 상품이 모두 반려될 수 있어요. Google 판매자 계정 삭제·관리자 권한 삭제도 이용 불가를 유발하니 유의하세요.
자주 묻는 CS
❓
채널 연결 관련
연결 실패 · 권한 · YPP · 국가 설정
▼
유튜브 채널 연결 실패 메시지가 떠요.
채널의 소유자 또는 관리자 권한이 있는지 YouTube 스튜디오에서 먼저 확인하세요. 연동하려는 채널이 YPP(유튜브 파트너 프로그램)를 만족해야 정상 연동돼요.
연결하려는 채널이 목록에 안 보여요.
'다른 계정으로 연결하기'를 통해 채널 목록을 다시 가져올 수 있어요. 유튜브 로그인 팝업에서 연결 가능한 채널이 있는 계정(브랜드 계정 포함)으로 로그인하세요.
연동은 됐는데 '채널의 국가 설정을 확인해 주세요'가 떠요.
유튜브 스튜디오 '설정 > 채널 > 기본정보'에서 거주 국가를 선택해야 유튜브 쇼핑을 정상 이용할 수 있어요.
잘 쓰다가 갑자기 '토큰에 문제가 발생했어요'가 떠요.
인증 토큰이 만료된 상태예요. 확인 필요 탭에서 '유튜브 재로그인하기'(판매자 센터는 '다시 로그인하기')로 재로그인하면 알림이 자동으로 사라져요.
채널을 변경하고 싶어요.
채널은 1개만 선택 가능하며 선택 후 변경이 어려우므로 신중히 결정해야 해요.
⏳
상품 승인 관련
승인 소요 시간 · 보류/반려 · 품목별 상태
▼
상품 승인까지 얼마나 걸리나요?
Google 검토 중인 '대기' 상태는 보통 2~3일 이내 반영돼요. 연동 직후에는 전체 상품 전송 자체에도 시간이 걸릴 수 있어요.
상품이 '보류'로 되어 있어요.
카페24 내부 기준에 맞지 않아 Google에 전송하지 않은 상태예요. 상품명에 개인결제류 단어가 있는지, 판매가 0원·2,000만원 초과인지, 대표이미지·진열·신상품·성인인증 설정을 확인하고 수정하면 자동 전송돼요.
상품에 문제가 없는데 '반려'됐어요.
상품 정보에 문제가 없어도 Google 쇼핑 광고 정책에 걸리면 반려될 수 있어요. 판매자 센터의 상품 상세에서 반려 사유를 확인하고 수정하면 자동 재심사돼요.
같은 상품인데 옵션마다 상태가 달라요.
상품은 품목 단위로 심사돼서 품목마다 상태가 다를 수 있어요. 상품 피드 상세에서 승인상태 뱃지를 눌러 품목별 사유를 확인하세요. 독립선택형의 선택 옵션 품목은 '대기'로 보일 수 있지만 판매에는 문제가 없어요.

결제·PG 관련
PG 조건 · 결제 프로필 · 카드 등록
▼
유튜브 쇼핑 연동이 언제 가능한가요?
쇼핑몰 PG(결제) 신청이 완료되어야 구글 & 유튜브를 시작할 수 있어요. PG 심사 관련은 쇼핑몰 결제 설정을 확인하세요.
제휴 프로그램 결제 설정에서 카드 등록이 안 돼요.
제휴 프로그램은 American Express·MasterCard·Visa의 해외 또는 국내/외 겸용 카드만 등록 가능해요. 국내용 카드는 등록할 수 없어요. 카드를 등록해도 실제 결제는 되지 않으며, 카드사 확인 문자가 발송될 수 있어요.
'월별 정기 결제'라고 나오는데 돈이 나가나요?
표시만 그렇게 될 뿐 실제 결제는 진행되지 않아요. 수수료 자동 정산을 위한 등록 절차예요.

계정 변경·해제 관련
Google 계정 변경 · 연결 해제
▼
Google 계정을 바꾸고 싶어요.
구글 & 유튜브 > 설정 > 계정 설정에서 연결된 계정을 확인하고 각 서비스 카드 우측 버튼으로 연동을 해제할 수 있어요. 단, Google 판매자 센터를 해제하면 모든 서비스가 해제되니 유의하세요.
유튜브 쇼핑을 삭제하면 어떻게 되나요?
유튜브 쇼핑을 삭제하면 해당 멀티샵의 모든 설정 정보가 삭제·초기화돼요. 다시 이용하려면 새롭게 유튜브 쇼핑 시작하기를 진행해야 해요.

주문·운영 관련
주문 관리 위치 · 상품 노출/정렬 · 성과 집계
▼
유튜브에서 들어온 주문을 어디서 관리하나요?
카페24 어드민의 '주문' 메뉴에서 기존 쇼핑몰 주문과 통합 관리돼요. 별도 탭으로 분리되지 않으며, 유튜브 쇼핑의 주문·반품·결제를 카페24 관리자에서 간편하게 관리할 수 있어요.
스토어에 상품이 안 보여요.
스토어·채널에 표기되는 상품은 최대 30개예요. 상품이 검색되지 않으면 상품 피드에서 유튜브 쇼핑 프로그램의 승인 상태·상품 정보를 확인하세요.
유튜브에 보이는 상품 순서를 바꾸고 싶어요.
기본은 가격·인기도·재고 등으로 자동 정렬돼요. 직접 정렬하려면 YouTube 스튜디오 수익 창출 > 쇼핑 탭 > '직접 제품 선택하기'(이미 변경한 적 있으면 '맞춤 설정')에서 최대 30개를 드래그로 정렬 후 저장하세요. 자동으로 되돌리려면 '자동 선택으로 돌아가기'를 눌러요.
⚠️
채널 단위 정렬은 실시간 스트림에는 적용되지 않아요. 개별 영상·라이브는 스튜디오 > 콘텐츠 > 영상 세부정보 > '제품'에서 따로 정렬하고, 선택을 비운 채 저장하면 해당 영상의 제품 섹션이 꺼져요.
유튜브 쇼핑 분석 매출이 실제보다 적게 잡혀요.
제휴 프로그램 주문은 분석에 합산되지 않아요(제휴 프로그램 성과에서 별도 확인). 또 UTM 파라미터가 유실된 주문이나 유튜브 외 경로 주문은 집계되지 않고, 분석은 2026년 1월 5일 이후 성과부터 제공돼요.
