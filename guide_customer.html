회원 검색/조회 관련
특정 조건 검색 · 부운영자 권한 · SNS 회원
▼
특정 조건으로 회원 검색을 하려면 어떻게 해야 하나요?
[관리자] 고객 > 회원 조회에서 상세 검색을 활용하면 가입일·구매이력·등급·지역 등 다양한 조건으로 회원 검색이 가능. 단순 검색으로 부족한 경우 상세 검색 활용 필요.
부운영자가 회원정보를 조회할 때 검색조건을 입력하라고 떠요
부운영자 계정에 회원 정보 검색 권한 제한이 적용되어 있어서 발생하는 현상. 이름·아이디가 정확히 일치해야 검색되도록 제한되어 있음. 모든 조건 검색이 필요하면 운영자 계정 관리에서 해당 부운영자의 권한 설정 변경 필요.
회원이 비밀번호를 분실한 경우 임시 비밀번호 발송해줄 수 있나요?
관리자 어드민에서 운영자가 임의로 비밀번호 발급은 불가능. 회원이 직접 쇼핑몰 로그인 화면의 비밀번호 찾기 기능을 통해 본인 인증 후 재설정해야 함. 보안 정책상 운영자가 회원 비밀번호에 접근할 수 없음.
SNS 로그인 기능으로 가입한 회원들만 조회할 수 있나요?
[관리자] 고객 > 회원 조회에서 상세 검색 → 가입 경로 또는 SNS 연동 항목으로 조건 설정하여 검색 가능.

회원 등급 관련
자동 변경 · 고정 등급 · 등급별 혜택
▼
고객 구매에 따라 회원 등급을 자동으로 변경하고 싶어요
[쇼핑몰 설정] 고객 설정 > 회원 정책 설정 > 회원 등급 관리에서 회원등급 자동 변경 설정을 통해 일정 기간 구매 이력에 따라 등급이 자동 변경되도록 설정 가능. 등급 기준·변경 기준을 설정하고 회원등급 목록에 우선 순위 입력 필요.
회원 등급이 자동변경 되지 않도록 고정하려면 어떻게 해야 하나요?
최하위 등급 윗등급에 관리용 등급을 설정하면 자동변경에서 제외 가능. 직원용·내부용 등 등급을 고정해야 하는 회원을 관리하는 용도로 사용. 자동 변경 대상에서 제외되어 등급이 유지됨.
회원 등급별로 적립금을 지급할 수 있나요?
[관리자] 고객 > 회원 관리에서 회원 등급별로 조회 후, 등급 전체에 적립금 일괄 지급 가능. 정기적인 등급별 혜택 지급에 활용.

▼
일정 기간 사용하지 않은 적립금이 소멸하도록 설정할 수 있나요?
가능. [관리자] 고객 > 회원 혜택 관리에서 수동/자동 소멸 처리 가능. 단, 소멸 정책 적용 전 약관 개정 + 최소 30일 전 고객 고지가 법적으로 필요. 약관에 명시되지 않은 임의 소멸은 법적 분쟁 소지가 있어 주의.
